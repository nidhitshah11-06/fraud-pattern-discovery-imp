# Dataset

This project uses the **PaySim synthetic financial transaction dataset**.

The raw dataset is not included in this repository because it contains
approximately 6.3 million transactions and is too large to include
directly in the GitHub repository.

## Dataset Setup

Download the PaySim dataset from its original public source and place
the CSV file inside this directory.

The expected file is:

```text
data/
└── PS_20174392719_1491204439457_log.csv
