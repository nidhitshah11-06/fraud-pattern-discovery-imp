# Financial Fraud Pattern Discovery using FP-Growth

## Overview

This project applies **Association Rule Mining using the FP-Growth algorithm** to discover recurring transaction patterns associated with financial fraud.

The system is designed as a **bank-side fraud analytics prototype** that can help fraud analysts understand combinations of transaction characteristics that occur disproportionately among fraudulent transactions.

> **Note:** This project focuses on pattern discovery and analysis, not standalone fraud detection or automated fraud decisions.

---

## Problem Statement

Financial institutions process large volumes of transactions, making it difficult for analysts to manually identify recurring combinations of behaviours associated with fraudulent activity.

This project uses FP-Growth to discover frequent transaction patterns and association rules that may help analysts identify potentially interesting fraud-related behaviours.

---

## Objectives

* Discover frequent transaction patterns using FP-Growth.
* Generate fraud-associated association rules.
* Evaluate rules using **Support, Confidence, and Lift**.
* Identify transaction characteristics strongly associated with fraud.
* Provide an interactive dashboard for analysing discovered rules.

---

## Dataset

The project uses the **PaySim synthetic financial transaction dataset**.

The dataset contains approximately **6.3 million simulated financial transactions** with attributes such as:

* Transaction type
* Transaction amount
* Origin account balance
* Destination account balance
* Simulation time
* Fraud label

Real banking transaction data is confidential, so a publicly available synthetic dataset is used for experimentation.

## Feature Engineering

The following transaction characteristics were converted into categorical items for association mining:

* Transaction type
* Transaction amount category
* Balance change category
* Simulation-time category
* Fraud label

### Transaction Amount

Transaction amounts were divided into four categories:

* `LOW`
* `MEDIUM`
* `HIGH`
* `VERY_HIGH`

### Simulation Time

The PaySim simulation steps were grouped into four time categories:

* `MORNING`
* `AFTERNOON`
* `EVENING`
* `NIGHT`

### Transaction Types

The analysis was restricted to:

* `TRANSFER`
* `CASH_OUT`

These transaction types were selected because all fraudulent transactions in the analysed PaySim data occur within these two categories.

---

## FP-Growth

**FP-Growth (Frequent Pattern Growth)** was used to discover frequent itemsets efficiently without generating candidate itemsets in the same manner as Apriori.

The analysis used:

* Minimum support: `0.0005`
* Support
* Confidence
* Lift

The resulting frequent itemsets were used to generate association rules, after which rules having `FRAUD` as the consequent were selected for fraud-associated pattern analysis.

---

## Results

The analysis produced:

* **670 frequent itemsets**
* **10 final fraud-associated rules**

The strongest discovered rule was:

```text
BALANCE_CHANGE_VERY_HIGH + TIME_NIGHT → FRAUD
```

with approximately:

* **Support:** `0.000661`
* **Confidence:** `30.20%`
* **Lift:** `101.87`

The high lift indicates that this combination is associated with the fraud label substantially more often than would be expected from the overall fraud baseline in the analysed dataset.

These results represent **statistical associations**, not proof that a transaction is fraudulent.

## Limitations

* The PaySim dataset is **synthetic** and may not fully represent real-world banking behaviour.
* Some balance-related attributes are closely connected to the fraud-generation mechanism in the simulated dataset.
* Association rules identify statistical relationships and do not establish causation.
* The discovered patterns should be treated as **analytical signals**, not standalone fraud decisions.
* The simulation-time categories represent PaySim's simulated timeline and should not be interpreted as actual customer clock-time behaviour.

## Conclusion

This project demonstrates how **FP-Growth-based Association Rule Mining** can be used to discover interpretable combinations of transaction characteristics associated with financial fraud.

Rather than replacing existing fraud detection systems, the approach can provide an additional analytical layer that helps fraud analysts understand recurring behavioural patterns and identify combinations that may warrant further investigation.
